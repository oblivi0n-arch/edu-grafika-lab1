# Zadanie 1 – podstawy operacji na obrazach w Pythonie

Zadanie z zajęć z grafiki komputerowej (WSB). Notebook `zadanie1.ipynb` wczytuje obraz (lokalnie i zdalnie), wyświetla go, zmniejsza o 50%, konwertuje do skali szarości, obraca o 90° i wypisuje macierz pikseli.

**Wymagania:** Python 3, `opencv-python`, `numpy`, `matplotlib`
**Obraz:** [Lemons for sale, Wikimedia Commons](https://commons.wikimedia.org/wiki/Category:Lemon) (`lemon.jpeg`)
